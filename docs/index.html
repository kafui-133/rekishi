このアプリの内容について

このアプリの出来事・人物・天皇・元号・各国の君主や指導者・年代・説明文・出来事どうしのつながり、および勢力図の日本語の国名と色分けは、生成AI（Claude）が作成したものです。資料と一件ずつ照らし合わせる確認はしていないため、年代・名前・内容に誤りが含まれている可能性があります。

学習や調べものに使うときは、教科書・事典・専門書などの信頼できる資料で確かめてください。

特に注意が必要な点

  • 第1代神武天皇から第9代ごろまでの年代は『日本書紀』の伝承によるもので、史実とは考えられていません。
  • 元号の年は西暦の年単位で区切っています。改元した月のずれは反映していません。
  • 出来事の場所や船の航路はおおよその位置で、実際の経路とは異なることがあります。
  • 君主・指導者は主な人物だけを登録しているため、表示されない期間があります。
  • 勢力図の境界はおおまかなもので、約40の時点のデータを近い年に当てはめて表示しています。主要国以外は表示していません。
  • 「国別」の色分けは現在の国境です。
